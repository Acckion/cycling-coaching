# Workout starting points

Adapted from the primary skill's templates, with secondary progression and execution review. These are selectable examples, not an athlete's standing prescription. Refresh live FTP/zones. Listed cadence is optional natural guidance; do not claim one universally optimal cadence.

| Session | Main work examples | Recovery | Purpose / progression |
|---|---|---|---|
| Recovery | 20–45 min Z1, often <55% FTP | None | Optional easy movement; rest can be preferable |
| Endurance | 45–120+ min power Z2, select e.g. 60–70% | As route requires | Add sustainable duration with steady response |
| Tempo | 2×15 to 2×25 min, e.g. 80–87% | 4–6 min Z1 | Moderate sustained work and pacing |
| SS | 2×12 → 2×15 → 2×20 min, e.g. 88–94% | 4–6 min Z1 | Accumulate subthreshold work; extend before raising power |
| Threshold | 2×10/12 → 2×15 → 2×20 min, e.g. 95–100% | 5–8 min Z1 | Repeatable threshold work; finish controlled, not maximal |
| VO₂-focused | e.g. 4–5×3–5 min, initial 106–120% adjusted to athlete | 3–5 min easy | Hard repeatable aerobic work; monitor delivered power and RPE |
| Longer hard reps | e.g. 3–4×8 min | 3–4 min easy initially | Choose sustainable power for total dose, often below shorter-rep power; no fixed 115% rule |

Most quality sessions use 15–20 min progressive warmup and 5–10 min easy cooldown. Optional short controlled openers can prepare for work, but are not all-out sprints and should not create early fatigue. Keep genuine recovery easy; HR need not reach a fixed low number in a brief recovery.

Example 60-minute SS workout (15 + 15 + 5 + 15 + 10 = 60):

```text
Warmup
- 5m 45-55%
- 5m 60-70% 80-95rpm
- 5m 75-80% 80-95rpm

Main
- 15m 88-92% 80-95rpm
- 5m 45-55%
- 15m 88-92% 80-95rpm

Cooldown
- 10m ramp 55-40%
```

Example 90-minute threshold + endurance workout (20 + 15 + 6 + 15 + 24 + 10 = 90):

```text
Warmup
- 10m ramp 45-65%
- 5m 65-75% 80-95rpm
- 5m 75-85% 80-95rpm

Main
- 15m 95-100% 80-95rpm
- 6m 45-55%
- 15m 95-100% 80-95rpm
- 24m 60-70% 80-95rpm

Cooldown
- 10m ramp 55-40%
```

For either: start at the lower target, use smooth power, avoid catching up after traffic, and downgrade remaining work if the first rep is already near maximal. Do not automatically progress after one easy-feeling ride. Shorten the endurance tail before sacrificing key work when the time budget shrinks.

For longer endurance rides, start near the lower selected Z2 target and assess whether late-ride output and RPE remain stable. Tailor fueling to duration and previous meals. Cadence drills are optional technique work, not a second hidden threshold session; avoid compulsory low-cadence high-torque work for an athlete with current leg symptoms.
